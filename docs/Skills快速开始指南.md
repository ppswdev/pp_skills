## 一、快速开始

### 1. 第一步：安装 skill-creator（必须）

**方式1：让 SOLO 帮你安装（最推荐）**
```
帮我安装 skill-creator 技能到当前项目
```

**方式2：手动安装**
```bash
git clone https://github.com/anthropics/skills.git
cp -r skills/skills/skill-creator .trae/skills/
```

### 2. 第二步：创建你的第一个自定义 Skill

在 Trae 的 SOLO 模式中输入：
```
用 skill-creator 帮我创建一个 Excel 数据处理的 Skill，功能包括：
- 读取 Excel 文件
- 数据清理和格式化
- 生成数据统计报告
- 导出为 CSV 和 JSON
```

### 3. 第三步：使用 ui-ux-pro-max 美化界面

**安装**：
```bash
# 全局安装 CLI
npm install -g uipro-cli

# 安装到 Trae
uipro init --ai trae
```

**使用示例**：
```
用 ui-ux-pro-max 技能，帮我设计一个响应式的用户管理系统界面，包含：
- 登录页面
- 仪表盘
- 用户列表
- 搜索和筛选功能
- 移动端适配
```

## 三、常见问题解决方案

### 问题1：技能未生效

**解决方案**：
1. ✅ 检查目录结构：`.trae/skills/skill-name/SKILL.md`
2. ✅ 完全重启 Trae IDE（关闭所有窗口再打开）
3. ✅ 检查 `SKILL.md` 文件格式是否正确（YAML frontmatter）
4. ✅ 确保文件夹名为 kebab-case 格式（小写+连字符）

### 问题2：技能冲突

**解决方案**：
1. ✅ 项目技能优先级高于全局技能
2. ✅ 重命名冲突的技能，避免同名
3. ✅ 只保留最常用的版本，清理冗余

### 问题3：Python 脚本运行失败

**解决方案**：
1. ✅ 检查 Python 版本：`python3 --version`（需要 3.x）
2. ✅ 安装依赖：`pip3 install -r requirements.txt`
3. ✅ 确保路径正确，脚本权限可执行
4. ✅ 检查网络连接（某些技能需要下载资源）

## 四、Skills 最佳实践

### 1. 技能命名规范
- 使用 **kebab-case** 格式：`ui-ux-pro-max`
- 简洁明了，描述核心功能
- 避免与其他技能重名

### 2. 技能管理
- **全局技能**：只保留 5-10 个高频使用的
- **项目技能**：按需安装，用完即清
- **本地备份**：定期备份重要技能到本地
- **版本控制**：将技能放在 Git 仓库中管理

### 3. 安全注意事项
- 只从正规渠道下载技能（GitHub、官方社区）
- 检查技能的代码和权限，避免安全风险
- 定期更新技能版本，获取安全修复
- 对于未知来源的技能，先在测试环境试用

### 4. 性能优化
- 不要安装过多技能，避免性能损耗
- 定期清理不用的技能，保持技能列表整洁
- 优先使用轻量级技能，减少资源占用
- 全局技能只装通用工具，项目技能装特定功能

## 五、进阶技巧

### 1. 技能组合使用

**示例**：
```
先用 requirements-analyst 分析需求，然后用 fullstack-developer 实现，最后用 ui-ux-pro-max 美化界面
```

**优势**：
- 充分发挥各技能的专长
- 流程化处理复杂任务
- 提高代码质量和开发效率

### 2. 自定义技能模板

**方法**：
1. 基于现有技能修改
2. 添加项目特定的规则和流程
3. 分享给团队使用
4. 持续迭代优化

**示例**：
- 公司代码规范技能
- 项目特定的部署流程
- 团队协作规范技能

### 3. 技能版本控制

**建议**：
- 将技能放在 Git 仓库中
- 使用分支管理不同版本
- 团队协作共享技能库
- 定期同步更新

**目录结构示例**：
```
My-Skills-Library/
├── frontend/
├── backend/
├── devops/
└── product/
```
