# Skills 使用教程

## 1. 如何创建一个 Skills

### 1.1 基本概念

Skills 是 Trae 中的功能模块，用于实现特定的任务自动化。每个 Skill 都有自己的目录结构和配置文件。

### 1.2 创建步骤

1. **创建目录结构**
   - 在项目根目录下创建 `.trae/skills/<skill-name>/` 目录
   - 例如：`.trae/skills/pp-tran/`

2. **创建 SKILL.md 文件**
   - 在技能目录中创建 `SKILL.md` 文件
   - 文件包含 frontmatter 和详细内容两部分

3. **配置 frontmatter**
   ```markdown
   ---
   name: "skill-name"
   description: "技能描述，包括功能和使用场景"
   ---
   ```

4. **编写详细内容**
   - 包括功能描述、使用场景、如何使用、工作原理等
   - 提供示例和注意事项

### 1.3 示例：创建 pp-tran Skill

```bash
# 创建目录
mkdir -p .trae/skills/pp-tran

# 创建 SKILL.md 文件
cat > .trae/skills/pp-tran/SKILL.md << 'EOF'
---
name: "pp-tran"
description: "自动以简体中文为基准翻译国际化文本文件，支持增量翻译，处理l10n目录下的语言文件。当用户需要同步翻译其他语言文件时调用。"
---

# 国际化文本翻译工具

## 功能描述

本工具用于自动将国际化文本文件以简体中文为基准进行翻译，支持增量翻译，避免全量翻译的繁琐工作。翻译时会符合目标国家的语言文化习惯和标准用语风格，确保翻译质量。

## 使用场景

- 当你开发中需要翻译大量国际化文本内容时
- 当你修改了简体中文文本后需要同步到其他语言时
- 当你需要保持多语言文件内容一致性时

## 如何使用

1. **基本使用**
   - 说明："按照简体中文进行生成"
   - 工具会自动扫描指定的l10n目录
   - 以简体中文文件为基准，翻译其他所有语言文件
   - 采用增量翻译方式，只翻译新增或修改的内容

2. **参数说明**
   - **目录路径**：默认扫描项目中的l10n目录，也可指定其他目录
   - **基准语言**：默认使用简体中文(zh-CN)作为基准
   - **目标语言**：默认翻译除基准语言外的所有语言文件
   - **翻译模式**：默认增量翻译，可指定全量翻译

3. **示例命令**
   - "按照简体中文进行生成" - 使用默认设置
   - "按照简体中文进行生成，目录路径为src/locales" - 指定目录
   - "按照简体中文进行生成，使用全量翻译" - 强制全量翻译

## 工作原理

1. **文件扫描**：扫描指定目录下的所有语言文件
2. **基准识别**：识别简体中文文件作为翻译基准
3. **差异分析**：分析其他语言文件与基准文件的差异
4. **增量翻译**：只翻译新增或修改的内容，同时确保翻译符合目标国家的语言文化习惯和标准用语风格
5. **文化适配**：根据目标语言的文化背景进行适当调整，确保翻译自然流畅
6. **文件更新**：更新翻译后的语言文件

## 支持的文件格式

- JSON格式
- YAML格式
- 其他常见的国际化文件格式

## 注意事项

- 确保基准语言文件(简体中文)内容完整准确
- 翻译结果会尽量符合目标国家的语言文化习惯和标准用语风格，但仍可能需要人工微调，特别是专业术语和文化特定表达
- 首次使用时会进行全量翻译，后续使用默认增量翻译
- 建议在翻译前备份语言文件，以防意外情况
- 对于重要内容，建议请目标语言的母语人士进行最终审核，确保翻译质量
EOF
```

## 2. 如何在 Trae 中使用 Skills

### 2.1 基本使用方法

1. **触发 Skills**
   - 在 Trae IDE 中，直接输入触发指令
   - 例如："按照简体中文进行生成"

2. **参数传递**
   - 可以在指令中添加参数
   - 例如："按照简体中文进行生成，目录路径为src/locales"

3. **查看执行结果**
   - Trae 会显示 Skills 的执行过程和结果
   - 可以查看生成的文件或执行日志

### 2.2 高级使用技巧

1. **组合使用**
   - 可以将多个 Skills 组合使用，实现复杂任务
   - 例如：先使用 pp-tran 翻译文本，再使用其他 Skills 进行处理

2. **自定义参数**
   - 根据 Skills 的说明，传递自定义参数
   - 例如：指定翻译目录、翻译模式等

3. **调试技巧**
   - 如果 Skills 执行出现问题，可以查看执行日志
   - 检查目录结构和配置文件是否正确

## 6. 常见问题

### 6.1 创建问题

**Q: 为什么我的 Skills 没有被识别？**
A: 检查目录结构是否正确，确保 `.trae/skills/<skill-name>/SKILL.md` 文件存在且格式正确。

**Q: Skills 描述应该包含什么内容？**
A: 描述应该包括技能的功能和使用场景，帮助模型决定何时使用该技能。

### 6.2 使用问题

**Q: 如何调试 Skills 的执行过程？**
A: 查看 Trae 的执行日志，检查是否有错误信息。

**Q: Skills 执行缓慢怎么办？**
A: 优化代码逻辑，使用缓存，避免不必要的操作。

### 6.3 发布问题

**Q: 如何确保 Skills 在不同环境下正常工作？**
A: 在不同环境下测试，提供详细的系统要求和依赖说明。

**Q: 如何处理用户反馈和 bug 报告？**
A: 建立反馈渠道，及时响应和修复问题。
