# Trae 中国版 Skills 全局配置指南

## 1. 全局技能 vs 项目技能

Trae 中国版 Skills 支持两种技能配置方式：

### 1.1 全局技能（Global Skills）

- **适用范围**：所有项目
- **用途**：个人工具或想在任何地方使用的通用工具
- **配置位置**：`~/.trae-cn/skills/<skill-folder>/`
- **特点**：一次配置，到处使用

### 1.2 项目技能（Project Skills）

- **适用范围**：仅当前项目
- **用途**：项目特定的工作流程、团队规范
- **配置位置**：`<workspace-root>/.trae/skills/<skill-folder>/`
- **特点**：项目专属，便于团队协作

## 2. 配置全局技能

### 2.1 使用安装脚本（推荐）

项目提供了便捷的安装脚本，可以一键将当前项目下的所有技能复制到全局目录：

```bash
# 运行安装脚本
./scripts/install-global-skills.sh
```

脚本功能：

- 自动检测项目根目录
- 自动创建全局技能目录
- 复制 `.trae/skills/` 下的所有技能到 `~/.trae-cn/skills/`
- 支持覆盖更新，确保使用最新版本
- 显示安装进度和结果

### 2.2 手动配置

#### 2.2.1 创建全局技能目录

```bash
# 创建全局技能目录（如果不存在）
mkdir -p ~/.trae-cn/skills
```

#### 2.2.2 复制技能到全局目录

```bash
# 将项目中的技能复制到全局目录
cp -r /path/to/your/project/.trae-cn/skills/your-skill-name ~/.trae-cn/skills/

# 示例：复制 pp-tran 技能
cp -r /Users/xiaopin/Desktop/AppDev/Projects/pp_skills/.trae-cn/skills/pp-tran ~/.trae-cn/skills/
```

#### 2.2.3 复制所有技能

```bash
# 复制当前项目下所有技能到全局目录
cp -r .trae-cn/skills/* ~/.trae-cn/skills/
```

### 2.3 重启 Trae IDE

复制完成后，重启 Trae IDE 让全局技能生效。

## 3. 全局技能的优势

### 3.1 一次配置，到处使用

- 配置一次后，所有项目都可以使用
- 无需在每个项目中重复复制

### 3.2 便于维护

- 更新技能时只需修改一个地方
- 所有项目自动使用最新版本

### 3.3 个人工具库

- 可以将常用的通用工具放在全局技能中
- 建立个人专属的 AI 工具箱

### 3.4 灵活管理

- 可以随时启用或禁用全局技能
- 支持在 IDE 设置中管理全局技能

## 4. 技能分类建议

### 4.1 适合作为全局技能的

- 通用工具（如 pp-tran、代码格式化）
- 跨项目的标准化流程
- 个人常用的开发辅助工具
- 代码生成模板
- 自动化脚本

### 4.2 适合作为项目技能的

- 项目特定的部署流程
- 团队代码规范检查
- 项目特定的测试惯例
- 团队特定的文档生成
- 项目相关的自动化任务

## 5. 实际操作示例

### 5.1 配置 pp-tran 为全局技能

```bash
# 1. 创建全局技能目录
mkdir -p ~/.trae-cn/skills

# 2. 复制 pp-tran 技能到全局目录
cp -r /Users/xiaopin/Desktop/AppDev/Projects/pp_skills/.trae-cn/skills/pp-tran ~/.trae-cn/skills/

# 3. 验证技能文件
ls -la ~/.trae-cn/skills/pp-tran/

# 4. 重启 Trae IDE
```

### 5.2 在任何项目中使用

配置完成后，在任何项目中都可以直接使用：

```
"按照简体中文进行生成"
```

无需再复制技能文件到项目中。

## 6. 管理全局技能

### 6.1 查看已安装的全局技能

```bash
# 列出所有全局技能
ls -la ~/.trae-cn/skills/
```

### 6.2 删除全局技能

```bash
# 删除指定的全局技能
rm -rf ~/.trae-cn/skills/your-skill-name
```

### 6.3 更新全局技能

```bash
# 重新复制技能到全局目录（覆盖）
cp -r /path/to/updated/skill ~/.trae-cn/skills/
```

## 7. 最佳实践

### 7.1 版本控制

- 将全局技能放在 Git 仓库中管理
- 使用 Git submodule 或符号链接管理
- 便于在不同机器间同步

### 7.2 文档维护

- 为每个全局技能编写清晰的文档
- 说明技能的用途、参数和注意事项
- 提供使用示例

### 7.3 定期清理

- 定期检查不再使用的全局技能
- 删除过时的技能，保持技能列表整洁
- 避免技能冲突

### 7.4 技能命名

- 使用清晰、描述性的技能名称
- 避免与其他技能命名冲突
- 遵循统一的命名规范

## 8. 故障排查

### 8.1 技能未生效

- 检查技能目录结构是否正确
- 确认 SKILL.md 文件格式正确
- 重启 Trae IDE

### 8.2 技能冲突

- 检查项目技能和全局技能是否有同名冲突
- 项目技能优先级通常高于全局技能
- 调整技能名称避免冲突

### 8.3 权限问题

- 检查全局技能目录的读写权限
- 确保 Trae IDE 有访问权限

## 9. 总结

全局技能是 Trae Skills 的强大功能，让你能够：

- 建立个人专属的 AI 工具库
- 在所有项目中复用常用技能
- 提高开发效率，减少重复配置
- 集中管理和维护技能

通过合理使用全局技能和项目技能，你可以构建一个高效、灵活的 AI 辅助开发环境。
