# pp-tran 使用指南

`pp-tran` 是 `pp-translator` 的简称，用来处理国际化语言文件的翻译、补齐和增量同步。

## 包内容

```
pp-tran/
├── SKILL.md
├── README.md
├── CONFIG.md
├── 使用指南.md
└── references/
    └── 国际化各个国家地区策略指南.md
```

## 快速开始

### 1. 增量同步所有语言

```text
用 pp-tran 同步翻译多语言
```

适合刚修改了中文或英文基准语言文件，希望补齐其他语言文件。

### 2. 只翻译新增内容

```text
只翻译我刚加的这几个 key 到日文和韩文
```

适合日常开发中只新增几个文案 key，不希望影响其他已有翻译。

### 3. 指定基准语言

```text
按照英文为基准补齐其他语言
按照简体中文为基准生成日文、韩文、德文
```

当项目同时存在中文和英文时，可以明确指定基准语言。

## 推荐工作流

1. 在基准语言文件中新增或修改 key-value。
2. 明确告诉 agent 使用 `pp-tran`。
3. 指定目标语言，或让 agent 自动识别所有目标语言。
4. 要求保持原文件格式、占位符、转义字符和元数据。
5. 翻译完成后检查报告中的新增 key、修改 key 和需要人工审核的条目。

## 支持格式

| 类型 | 示例 |
| --- | --- |
| Flutter ARB | `lib/l10n/app_en.arb`、`lib/l10n/app_zh.arb` |
| iOS strings | `en.lproj/Localizable.strings` |
| JSON | `src/locales/en.json` |
| YAML | `src/i18n/en.yaml` |

## 注意事项

- 首次补齐语言时可能是全量翻译，后续默认增量翻译。
- UI 文案要控制长度，避免按钮、标签、弹窗标题过长。
- 含变量占位符的文本必须保持占位符不变。
- 阿拉伯语等 RTL 语言需要额外检查 UI 方向和布局。
- 涉及文化、宗教、法规、支付、隐私等内容时，建议人工复核。
