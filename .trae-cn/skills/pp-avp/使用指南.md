## 🚀 快速开始

**macOS:**

## 💡 常用命令示例

### 视频处理

#### 视频压缩
```bash
ffmpeg -i input.mp4 -c:v libx264 -preset slow -crf 23 -c:a copy output.mp4
```

#### 视频格式转换
```bash
# MP4 转 AVI
ffmpeg -i input.mp4 -c:v libx264 -c:a aac output.avi

# MP4 转 WebM
ffmpeg -i input.mp4 -c:v libvpx -c:a libvorbis output.webm
```

#### 视频剪辑
```bash
# 截取 30秒 到 60秒
ffmpeg -i input.mp4 -ss 00:00:30 -to 00:01:00 -c copy output.mp4

# 前 30秒
ffmpeg -i input.mp4 -t 30 -c copy output.mp4
```

#### 调整分辨率
```bash
# 缩放到 720p
ffmpeg -i input.mp4 -vf "scale=1280:720" -c:v libx264 -crf 23 output.mp4

# 保持宽高比缩放
ffmpeg -i input.mp4 -vf "scale=1280:-1" -c:v libx264 -crf 23 output.mp4
```

#### 添加水印
```bash
# 图片水印
ffmpeg -i input.mp4 -i logo.png -filter_complex "overlay=10:10" output.mp4

# 文字水印
ffmpeg -i input.mp4 -vf "drawtext=text='版权':fontsize=24:fontcolor=white:x=10:y=10" output.mp4
```

### 音频处理

#### 提取音频
```bash
# 从视频提取音频
ffmpeg -i input.mp4 -vn -c:a libmp3lame -b:a 128k output.mp3

# 保持原格式
ffmpeg -i input.mp4 -vn -acodec copy output.aac
```

#### 音频格式转换
```bash
# WAV 转 MP3
ffmpeg -i input.wav -c:a libmp3lame -b:a 192k output.mp3

# FLAC 转 AAC
ffmpeg -i input.flac -c:a aac -b:a 128k output.m4a
```

#### 调整音量
```bash
# 增加音量
ffmpeg -i input.mp3 -af "volume=2.0" output.mp3

# 降低音量
ffmpeg -i input.mp3 -af "volume=0.5" output.mp3
```

### 视频转 GIF/WebP

#### 视频转 GIF
```bash
# 基础转换
ffmpeg -i input.mp4 -r 10 output.gif

# 优化 GIF（推荐）
ffmpeg -i input.mp4 -vf "scale=640:-1" -r 10 output.gif
```

#### 视频转 WebP
```bash
ffmpeg -i input.mp4 -c:v libwebp -lossless 0 -q:v 80 -preset default -an output.webp
```

### 提取视频帧

```bash
# 提取第 10秒 的帧
ffmpeg -i input.mp4 -ss 00:00:10 -vframes 1 output.jpg

# 每秒提取一帧
ffmpeg -i input.mp4 -vf "fps=1" frame_%04d.jpg
```

### 视频合并

```bash
# 创建文件列表
echo "file 'video1.mp4'" > list.txt
echo "file 'video2.mp4'" >> list.txt

# 合并视频
ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4
```

## 📊 常用参数说明

### 视频参数
| 参数 | 说明 | 示例 |
|------|------|------|
| `-i` | 输入文件 | `-i input.mp4` |
| `-c:v` | 视频编码器 | `-c:v libx264` |
| `-b:v` | 视频比特率 | `-b:v 1000k` |
| `-crf` | 质量因子 | `-crf 23` |
| `-preset` | 编码预设 | `-preset slow` |
| `-r` | 帧率 | `-r 30` |
| `-s` | 分辨率 | `-s 1920x1080` |

### 音频参数
| 参数 | 说明 | 示例 |
|------|------|------|
| `-c:a` | 音频编码器 | `-c:a aac` |
| `-b:a` | 音频比特率 | `-b:a 128k` |
| `-ar` | 采样率 | `-ar 44100` |
| `-ac` | 声道数 | `-ac 2` |
| `-vn` | 禁用视频 | `-vn` |

### 时间参数
| 参数 | 说明 | 示例 |
|------|------|------|
| `-ss` | 开始时间 | `-ss 00:00:30` |
| `-to` | 结束时间 | `-to 00:01:00` |
| `-t` | 持续时间 | `-t 60` |

### 滤镜参数
| 参数 | 说明 | 示例 |
|------|------|------|
| `-vf` | 视频滤镜 | `-vf "scale=1280:720"` |
| `-af` | 音频滤镜 | `-af "volume=2.0"` |
| `-filter_complex` | 复杂滤镜 | `-filter_complex "overlay=10:10"` |

## 🎯 编码预设

### 速度 vs 质量

| 预设 | 速度 | 压缩率 |
|------|------|--------|
| ultrafast | 最快 | 最低 |
| veryfast | 快 | 中等 |
| fast | 较快 | 较高 |
| medium | 默认 | 高 |
| slow | 较慢 | 很高 |
| slower | 慢 | 极高 |
| veryslow | 最慢 | 最高 |

**建议**：
- 快速处理：`ultrafast` / `veryfast`
- 日常使用：`medium` / `fast`
- 高质量存档：`slow` / `slower`

### CRF 值参考

| CRF 值 | 质量 | 用途 |
|--------|------|------|
| 18-20 | 视觉无损 | 高质量存档 |
| 23 | 良好质量 | 推荐默认值 |
| 24-26 | 可接受质量 | 网络分享 |
| 28+ | 低质量 | 高度压缩 |

## 🔧 批量处理

### 批量转换音频格式
```bash
for file in *.flac; do
    ffmpeg -i "$file" -c:a aac -b:a 128k "${file%.flac}.m4a"
done
```

### 批量压缩视频
```bash
for file in *.mp4; do
    ffmpeg -i "$file" -c:v libx264 -preset slow -crf 23 -c:a copy "compressed_$file"
done
```

## 💡 高级技巧

### 硬件加速

**NVIDIA GPU:**
```bash
ffmpeg -hwaccel cuda -i input.mp4 -c:v h264_nvenc -preset p7 -cq 23 output.mp4
```

**Intel QSV:**
```bash
ffmpeg -hwaccel qsv -i input.mp4 -c:v h264_qsv -preset medium -global_quality 23 output.mp4
```

### 查看详细信息

```bash
# 查看文件信息
ffprobe -v quiet -print_format json -show_format -show_streams input.mp4

# 查看支持的编解码器
ffmpeg -codecs

# 查看支持的格式
ffmpeg -formats
```

## ❓ 常见问题

### Q: FFmpeg 命令不工作？
```bash
# 检查 FFmpeg 是否安装
which ffmpeg

# 如果没有安装，重新安装
brew reinstall ffmpeg
```

### Q: 输出文件太大？
```bash
# 使用更高的 CRF 值或更快的预设
ffmpeg -i input.mp4 -c:v libx264 -preset ultrafast -crf 28 output.mp4
```

### Q: 音视频不同步？
```bash
# 使用固定帧率
ffmpeg -i input.mp4 -vsync cfr -c:v libx264 -crf 23 output.mp4
```

### Q: 如何查看进度？
```bash
ffmpeg -i input.mp4 -progress pipe:1 output.mp4
```
