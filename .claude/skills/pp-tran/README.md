# pp-tran - 国际化多语言翻译技能包

`pp-tran` 是 `pp-translator` 的简称，用于 App / Web 项目的国际化语言文件翻译、增量同步和本地化质量检查。

## 目录结构

```
pp-tran/
├── SKILL.md
├── README.md
├── CONFIG.md
├── 使用指南.md
└── references/
    └── 国际化各个国家地区策略指南.md
```

## 核心能力

- 支持简体中文 `zh-CN` 和英文 `en` 双基准语言
- 支持新增 key、选中 key、指定 key 的增量翻译
- 支持 Flutter `.arb`、iOS `.strings`、JSON、YAML / YML
- 保持占位符、转义字符、复数规则和元数据结构稳定
- 按目标国家地区调整表达习惯、语气和术语

## 常见触发说法

```text
用 pp-tran 同步翻译多语言
只翻译我刚加的这几个 key
按照英文为基准补齐其他语言
把这些 arb 文件缺失的语言补齐
检查日文和韩文是否符合当地 App 表达习惯
```

## 参考文档

- `references/国际化各个国家地区策略指南.md`：国家和地区本地化策略。只有在需要文化适配、地区表达差异、语气风格判断时读取。

## 迁移说明

复制整个 `pp-tran/` 目录即可迁移技能。`SKILL.md` 是必需文件，其余说明和参考文档用于增强可维护性。
